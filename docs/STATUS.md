## Where the data stands

- `data/raw/<district>.json`: one file per district, written by the district scouts. Each entity has `instruments` and `instruments_detail`, annotated from the entity's own site. `data/raw/<district>.notes.md` records what was not added and why.
- `data/exclusions.json`: places removed on purpose (dead sites, duplicates, weak sources, poor fit). Scouts must not re-add them.
- `data/jobs.json`: generated by `scripts/merge.py`, `geocode.js` and `enrich_stations.js` (re-run them after any change to `data/raw/`).
- `dist/berlin-music-map.html`: built by `py scripts/build_map.py`.
